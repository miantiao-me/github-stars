[RSS Style](https://www.rss.style/) helps you make your [RSS and Atom feeds](https://en.wikipedia.org/wiki/Web_feed) look nice.

## Using

Instructions and links for all the different resources are on the [RSS Style website](https://www.rss.style/).

## Running

The website now runs on Astro with the Cloudflare Workers adapter.

Install dependencies:

```bash
npm install
```

Run locally with Astro dev server:

```bash
npm run dev
```

Build for Workers deployment:

```bash
npm run build
```

Preview the built Worker locally:

```bash
npm run preview
```
